# 컴포넌트 규칙

필요한 섹션만 읽는다. 값은 모두 `tokens.css` 토큰으로 쓴다.

## §1 버튼

| 종류 | 스타일 | 용도 |
|---|---|---|
| Primary | `--primary` 배경, `--on-primary` 글자, 높이 `--btn-h`, `--radius-sm`, 전체 폭, `--shadow-primary` | 화면당 1개 |
| Secondary | `--primary-light` 배경, `--primary` 글자 | 보조 액션 |
| Pill | 높이 `--btn-h-sm`, `--radius-full`, 좌우 14px | 카드 안 CTA |
| Text | 배경 없음, `--primary` 글자 | 전체 보기, 목표 수정 |
| Ink FAB | `--ink` 배경, 흰 + 아이콘, 52×52, `--radius-md` | 바텀 내비 중앙 생성 버튼 |
| Icon | 40×40 원형, `--surface` + 1px `--divider` | 알림, 설정, 뒤로가기 |

- 눌림: scale 0.97. 비활성: opacity 0.4.
- 시각적으로 작은 버튼도 터치 영역은 `--touch-min` 이상.
- 키보드·포커스 상태: `box-shadow: var(--focus-ring)`. outline 제거 후 대체 없이 두지 않는다.
- Primary 버튼 글자는 항상 `--on-primary` (다크 모드에서 어두운 글자로 바뀜).

## §2 카드

**히어로 카드** — `--radius-lg`, 패딩 `--space-5`. 왼쪽: 태그 + 제목 + 보조 정보 / 오른쪽: 진행 링 또는 일러스트 / Pill 버튼 1개. 배경은 `--surface` 또는 `--hero-gradient`(이때 글자 흰색, Pill 버튼은 흰 배경 + `--primary` 글자).

**요약 지표 카드 (2×2)** — 파스텔 배경, 그림자 없음, `--radius-md`, 최소 높이 100px.
```
5        〰〰   ← display 숫자 + 스파크라인(-ink 색)
오늘 할 일   >  ← body-sm 라벨 + 쉐브론
```

**상품/플랜 카드 (가로 스크롤)** — 폭 160~180px, 다음 카드가 30% 정도 보이게. 아이콘 타일 + 이름/부제 → 스펙 2줄 → 가격(title-sm 굵게) + `>`.

**리스트 행 카드** — 최소 높이 64px, `--radius-md`, 행 간격 10px. `[아이콘 타일] 제목/보조 정보 [배지] [>]`. 진행률이 있으면 제목 아래 4px 진행 바.

## §3 아이콘 타일

- `--icon-tile`(리스트) / `--icon-tile-lg`(퀵 액션), `--radius-sm`, 파스텔 배경 + `-ink` 아이콘(20~24px).
- 퀵 액션은 4열 그리드, 타일 아래 caption 라벨.

## §4 태그 · 배지 · 칩

- 태그: 높이 22px, `--radius-xs`, 파스텔 배경 + `-ink` 글자, caption.
- 상태 배지: `--success/warning/danger` 글자 + `-bg` 배경.
- 세그먼트 칩: 선택 = `--ink` 배경 + `--on-ink` / 미선택 = `--surface` + 1px `--divider`. 개수는 괄호로 "내 프로젝트 (5)".
- 알림 배지: 아이콘 우상단 16px 원, `--danger` 또는 `--peach-ink`.

## §5 바텀 내비게이션

- 하단 12px, 좌우 16px 띄운 플로팅 바. `--surface`, `--radius-lg`, `--shadow-float`. 하단 Safe Area 패딩 추가.
- 탭 4~5개. 생성 중심 앱은 가운데 Ink FAB.
- 활성: `--primary` 채움 아이콘 + 라벨(필요하면 `--primary-light` pill 배경) / 비활성: `--text-tertiary` 아웃라인.

## §6 헤더 · 팝오버

- 홈: 아바타(40 원형) + 인사말 / 오른쪽 알림 아이콘 버튼.
- 하위 화면: 뒤로가기 + 제목 + 오른쪽 액션(설정·필터).
- 단계형 화면: 헤더 아래 `3/10` + 진행 바 + 상태 아이콘.
- 섹션 헤더: 왼쪽 title-md / 오른쪽 Text 버튼 또는 기간 드롭다운(`--surface`, 1px `--divider`, radius 10px).
- 팝오버 메뉴: `⋮`에서 열림, `--surface`, `--radius-sm`, `--shadow-float`. 아이콘 + 텍스트, 삭제는 `--danger`.

## §7 진행 시각화

| 형태 | 언제 | 규칙 |
|---|---|---|
| 링 | 한도 대비 사용량 | 두께 10~14px, 끝 둥글게, 트랙 `--primary-light`, 채움은 `--primary` → `--accent` 그라데이션, 중앙 display 숫자 + 단위 |
| 진행 바 | 항목별 진행률, 단계 | 높이 4~8px, `--radius-full`, 트랙 `--divider` |
| 라인 차트 | 기간별 추이 | 곡선, 선 `--primary`, 선 아래 `--accent` 10~15% 그라데이션 면, 격자선 최소, 선택점 `--accent` 점 + 툴팁 |
| 스파크라인 | 요약 카드 추세 | 축·라벨 없음, 선 2px |
| 스트릭·배지 | 연속 기록, 보상 | 불꽃 아이콘 + 숫자, 원형 메달 + 2줄 라벨 |

- 툴팁: `--ink` 배경, `--on-ink` 글자, `--radius-xs`, 값(굵게) + 날짜(작게).
- 기간 필터는 차트 카드 오른쪽 위.
- 진입 시 0 → 현재 값으로 `--dur-progress` 동안 한 번만 채움.

## §8 캘린더

- 요일: caption + `--text-tertiary`.
- 선택일: `--ink` 원(36px) + `--on-ink` 숫자.
- 일정 있는 날: 숫자 아래 4px 점, 카테고리 `-ink` 색.
- 월 이동: 오른쪽 위 `<` `>`.

## §9 타임라인 리스트

```
○  할 일                     ← caption, --text-tertiary
   웹사이트 점검하기           ← title-sm
   오전 11:20 - 오후 12:20    ← body-sm, --text-secondary
────────────────────────────  ← --divider 1px
```
종류마다 아이콘 모양·색을 다르게(할 일 원, 일정 캘린더, 알림 종, 마일스톤 파이).

## §10 학습 · 퀴즈 화면

- 상단 지시문(title-sm) → 중앙 일러스트 + 말풍선(재생 버튼) → 단어 칩(`--surface` + 테두리, `--radius-sm`) → 정답 슬롯(점선 테두리 빈 박스) → 하단 Primary 버튼.
- 음성 입력: 중앙 72px 원형 Primary 마이크 + `--primary-light` 동심원 2겹 + 안내 문구.

## §11 모션

- 기본 `--dur` + `--ease`. 사용자 동작에 대한 반응(탭 전환, 시트, 펼침)에만 모션.
- 자동 반복 애니메이션 금지. 진행 채움은 진입 시 1회.
- 리스트 탭 피드백: 배경 `--surface-sub`.
- 축하 효과는 목표 달성·스트릭 갱신 순간에만.

## §12 문구 · 빈 화면 · 오류

- 인사 + 맥락: "안녕하세요, 지민님 / 이번 주 사용 현황이에요"
- 버튼 = 동작: "데이터 충전", "학습 이어하기". 완료 메시지와 같은 동사 사용.
- 빈 화면: 다음 행동 안내 + 버튼. "아직 프로젝트가 없어요. 첫 프로젝트를 만들어 보세요"
- 오류: 무엇이 잘못됐고 어떻게 고치는지. 사과·모호한 표현 금지.
- 날짜·숫자 표기는 앱 전체에서 한 형식(`12월 21일`, `1,234원`).

## §13 아이콘 · 일러스트

- 라운드 아웃라인, 선 1.5~2px, 24px 그리드, 한 세트만(Lucide 또는 Phosphor). 활성만 채움.
- 국기·브랜드 아이콘은 원형 마스크 32~40px.
- 일러스트는 히어로 카드와 빈 화면에만.
