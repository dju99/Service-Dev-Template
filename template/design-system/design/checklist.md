# 화면 검사 체크리스트

화면을 다 만든 뒤 항목마다 통과/위반을 표시하고, 위반은 고친 다음 고친 내용을 보고한다.

## 필수 (하나라도 위반이면 수정)

- [ ] hex 색, 임의 px radius·그림자 값을 직접 쓰지 않고 토큰만 썼다
- [ ] 배경 `--bg`, 카드 `--surface`
- [ ] 전체 폭 Primary 버튼이 화면에 1개 이하
- [ ] Primary 색이 버튼·활성 탭·진행 바·링크 외에 쓰이지 않았다
- [ ] `--accent`를 글자색으로 쓰지 않았다
- [ ] Primary 버튼 글자가 `--on-primary`다 (다크 모드에서 어둡게 바뀌는지 확인)
- [ ] 포커스 상태가 `--focus-ring`으로 보인다
- [ ] 핵심 지표가 display 숫자 + 작은 단위로 표시된다
- [ ] 진행 상황이 링·바·차트 중 하나로 시각화된다
- [ ] 카드에 테두리와 그림자를 동시에 쓰지 않았다
- [ ] 터치 영역 44×44px 이상
- [ ] 본문 텍스트 대비 4.5:1 이상, `--text-tertiary`를 본문에 쓰지 않았다

## 권장

- [ ] 좌우 여백 20, 섹션 간격 32, 카드 간격 12, 카드 패딩 16
- [ ] radius가 요소 크기별로 단계를 나눠 쓰였다
- [ ] 섹션 헤더 오른쪽 링크·필터 배치가 일관적이다
- [ ] 굵기가 400/600/700 세 단계뿐이다
- [ ] 아이콘 세트와 선 두께가 통일됐다
- [ ] 상태가 색만이 아니라 텍스트로도 구분된다
- [ ] 버튼 문구가 동작을 말하고 완료 메시지와 동사가 같다
- [ ] 빈 상태·로딩·오류 화면이 있다
- [ ] 다크 모드와 모션 줄이기 설정에서 깨지지 않는다
