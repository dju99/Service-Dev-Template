# 기초 규칙 — 색 · 글자 · 간격 · 모서리 · 그림자

값은 `tokens.css`에 있다. 이 파일은 **언제 어떤 토큰을 쓰는지**만 정한다.

## 1. 색

메인 색은 **민트**다.

| 용도 | 토큰 | 라이트 | 다크 |
|---|---|---|---|
| 페이지 배경 | `--bg` | #F1F3F5 | #131A22 |
| 카드·사이드바·팝업 | `--surface` | #FFFFFF | #1B242D |
| 주요 버튼·활성 상태 | `--primary` | #087D81 | #75DCD4 |
| 아이콘·포커스 포인트 | `--accent` | #1EBFC2 | #56D0CB |
| 기본 텍스트 | `--text-primary` | #1D1D1F | #EAF1F5 |
| 보조 텍스트 | `--text-secondary` | #676D73 | #A8B8C7 |

- `--primary`: 주요 버튼, 활성 탭·활성 상태, 진행 바, 텍스트 링크. 그 외 사용 금지.
- `--primary-light`: 선택된 항목 배경, 보조 버튼 배경, 진행 링 트랙.
- `--accent`: 아이콘, 포커스 링(`--focus-ring`), 차트 강조점, 진행 링의 밝은 끝. **글자색으로 쓰지 않는다** — 흰 배경에서 대비가 부족하다.
- 다크 모드의 `--primary`(#75DCD4)는 밝은 색이라 버튼 위 글자는 `--on-primary`(어두운 색)를 쓴다. 흰 글자 고정 금지.
- 민트 톤이 화면을 덮지 않게: 민트는 포인트, 면적의 대부분은 `--bg`·`--surface`.
- 파스텔(mint·sky·lavender·peach·butter): 같은 위계 항목을 나란히 놓을 때 구분용. 첫 번째 항목은 mint로 브랜드와 맞춘다. 배경은 파스텔, 안의 아이콘·선은 같은 계열 `-ink`.
- 상태 색은 작은 pill 배지에만 쓰고, 반드시 텍스트를 함께 둔다(색만으로 구분 금지).
- 그라데이션은 화면당 히어로 영역 1곳, `--hero-gradient`(민트 계열)만 쓴다.
- `--text-tertiary`는 라벨·날짜·비활성 탭 전용. 본문에 쓰지 않는다.

## 2. 글자

| 토큰 | 크기/행간 | 굵기 | 용도 |
|---|---|---|---|
| display | 32/38 | 700 | 핵심 지표 숫자 |
| title-lg | 24/32 | 700 | 화면 제목, 인사말 |
| title-md | 20/28 | 700 | 섹션 제목 |
| title-sm | 16/24 | 600 | 카드·리스트 항목 제목 |
| body | 15/22 | 400 | 본문 |
| body-sm | 13/18 | 400 | 보조 설명, 날짜, 단위 |
| caption | 11/14 | 500 | 차트 축, 탭 라벨, 배지 |

- 서체는 Pretendard 하나. 위계는 크기·굵기로만 만든다. 굵기는 400/600/700만.
- 숫자에는 `font-variant-numeric: tabular-nums`.
- 숫자 + 단위: 숫자 `display`, 단위 `body-sm` + `--text-secondary`.
- 인사말 2줄: 이름 굵게 / 맥락 설명 보통 굵기·흐린 색.
- 라벨을 대문자로만 쓰지 않는다. 문장형 기본.

## 3. 간격 · 레이아웃

- 4px 단위, 실제로는 8의 배수 위주.
- 화면 좌우 `--screen-x`(20), 섹션 간격 `--space-8`(32), 섹션 제목↔내용 `--space-3`~`--space-4`, 카드 사이 `--space-3`, 카드 패딩 `--space-4`(히어로는 `--space-5`).
- 고정 높이 대신 최소 높이를 써서 글자 확대에 대응한다. Safe Area 확보.

홈 화면 기본 구조:
```
[아바타] 인사말                [알림]
맥락 설명
[히어로 카드: 큰 숫자 + 진행 시각화 + CTA 1개]
섹션 제목                   전체 보기
[카드][카드][카드 →]   ← 가로 스크롤 또는 2열
섹션 제목                   전체 보기
[리스트 행 ............ >]
[플로팅 바텀 내비]
```

## 4. 모서리

| 토큰 | 값 | 대상 |
|---|---|---|
| radius-xs | 8 | 배지, 작은 칩, 툴팁 |
| radius-sm | 12 | 버튼, 인풋, 아이콘 타일, 팝오버 |
| radius-md | 16 | 일반 카드, 리스트 카드, 요약 카드 |
| radius-lg | 24 | 히어로 카드, 바텀 시트, 바텀 내비 |
| radius-full | 999 | pill 버튼, 탭 칩, 진행 바, 아바타 |

바깥 요소일수록 크게, 안쪽일수록 작게. 모든 요소를 같은 값으로 두지 않는다.

## 5. 그림자

- `--shadow-card`: 기본 카드
- `--shadow-float`: 바텀 내비, 팝오버, 툴팁
- `--shadow-primary`: Primary 버튼, FAB
- 카드는 그림자만, 테두리 없음. 흰 배경 위 리스트는 그림자 없이 `--divider` 1px로 구분.
- 다크 모드에선 그림자 대신 surface 명도 차이로 층을 나눈다.
