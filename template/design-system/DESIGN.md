# DESIGN.md — 앱 디자인 핵심 규칙

UI 코드를 작성하기 전에 이 파일을 먼저 읽는다. 상세 내용은 아래 "언제 무엇을 읽을지"를 따라 필요한 파일만 연다.

## 필수 규칙 (위반 금지)

1. 색·radius·그림자·간격 값을 직접 쓰지 않는다. 반드시 `design/tokens.css`(웹) 또는 `design/tokens.ts`(JS/RN)의 토큰을 쓴다.
2. 배경은 `--bg`, 카드는 `--surface`. 어두운 면은 Ink 버튼·선택 칩·툴팁에만 쓴다.
3. 메인 색은 민트. `--primary`는 주요 버튼·활성 상태·진행 바·텍스트 링크에만, `--accent`는 아이콘·포커스 포인트에만 쓴다(`--accent`로 글자 쓰기 금지). 전체 폭 Primary 버튼은 화면당 1개.
4. 화면의 핵심 지표는 `display`(32/700) 숫자 + 작은 단위로 보여주고, 진행 상황은 링·바·라인 차트 중 하나로 시각화한다.
5. 카드에 테두리와 그림자를 동시에 쓰지 않는다. radius는 바깥 요소일수록 크게(xs 8 → lg 24).

## 권장 규칙

- 화면 좌우 여백 20px, 섹션 간격 32px, 카드 간격 12px, 카드 패딩 16px
- 섹션 헤더: 왼쪽 제목(`title-md`), 오른쪽 "전체 보기" 링크 또는 기간 필터
- 바텀 내비는 하단에서 띄운 플로팅 형태, 활성 탭만 Primary
- 아이콘은 라운드 아웃라인 한 세트만, 활성 상태만 채움
- 버튼 문구는 동작 그대로("충전하기"), 완료 메시지와 일치("충전했어요")
- 터치 영역 44×44px 이상, 본문 대비 4.5:1 이상
